Analyze Document Relations

Document 간 관계 분석 및 생성 (Step 3)

Args: doc_id: 분석할 Document ID (None이면 전체 문서 분석) top_k: 관련 문서 최대 개수 (기본: 10) text_weight: 텍스트 유사도 가중치 (기본: 0.6) graph_weight: 그래프 임베딩 유사도 가중치 (기본: 0.4)

Flow: Step 1: /metadata/extract - 문서 추가 (text_embedding) Step 2: /graph/embeddings - 그래프 임베딩 생성 Step 3: /graph/relations/analyze - 관계 분석 ← 현재

Note: - 하이브리드 검색: 텍스트 + 그래프 임베딩 + 그래프 구조 - LLM으로 의미적 관계 추론 (EXTENDS, USES, PREREQUISITE_OF 등) - doc_id=null: 모든 문서에 대해 관계 분석 - 처리 시간이 오래 걸릴 수 있음 (문서 수 × top_k × LLM 호출)

Search Graph Rag

사용자 질의 기반 Graph RAG 검색

Args: request: GraphRAGSearchRequest - query: 사용자 질의 - top_k: 반환할 Document 개수 (기본: 5, 최대: 20)

Returns: GraphRAGSearchResponse - query: 사용자 질의 - documents: 검색된 Document 목록 (벡터 유사도 순) - common_metadata: 검색된 Document들의 공통 Category/Tag 집계 * categories: Category별 출현 빈도 및 비율 * common_tags: Tag별 출현 빈도 및 비율

Note: - 벡터 검색으로 관련 Document 찾기 - 공통 메타데이터(Category, Tag)를 집계하여 검색 결과 요약 제공 - 답변 생성(Generation)은 포함하지 않음

Response:
{

        {

        }
    ],
    "common_metadata": {

}
